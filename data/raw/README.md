# 📊 Análisis del E-Commerce en Brasil (Olist)

Este proyecto realiza un análisis de datos sobre el comportamiento de compra, logística y satisfacción de los clientes utilizando el conjunto de datos público de **Olist**, la plataforma de e-commerce más grande de Brasil.

## 💾 Sobre el Dataset

Debido a las restricciones de tamaño de archivo de GitHub, **los datos originales (`.csv`) no están incluidos en este repositorio**. 

Puedes descargar el dataset completo de manera gratuita directamente desde la fuente oficial en Kaggle:

[![Kaggle](https://shields.io)](https://kaggle.com)

### Instrucciones para ejecutar el proyecto localmente:
1. Descarga el archivo ZIP desde el enlace de Kaggle superior.
2. Descomprime los archivos `.csv`.
3. Guarda los archivos dentro de una carpeta llamada `/data` en la raíz de este proyecto.

## 🚀 Tecnologías Utilizadas
* Python 3
* Pandas & NumPy
* Matplotlib & Seaborn
* Jupyter Notebooks
