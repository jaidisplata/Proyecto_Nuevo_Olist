# Proyecto_Nuevo_Olist
Proyecto Olist: Análisis de datos con Power BI y Python.Proyecto independiente de análisis de datos desarrollado a partir del conjunto de datos, Brazilian E-Commerce Public Dataset by Olist.
Este proyecto tiene como objetivo analizar información de comercio electrónico mediante dos herramientas:
Power BI para el proceso de transformación, modelado, creación de medidas DAX y construcción del dashboard.
Python para realizar posteriormente la exploración, limpieza, análisis estadístico y visualización de los mismos datos.
El proyecto se desarrolla desde cero y mantiene separados los procesos realizados en Power BI y Python.
fuente de los datos Kaggle, este conjunto de datos tiene información relacionada con: pedidos, clientes, productos, vendedores, artículos vendidos, pagos, reseñas, ubicación geográfica, categorías de productos. los datos corresponden al conjunto público de comercio electrónico de Olist, disponible en Kaggle.
el objetivo del proyecto consiste en analizar los datos del comercio electrónico de Olist para identificar patrones relacionados con ventas, pedidos, clientes, productos, pagos, vendedores, ubicación geográfica y satisfacción de los clientes.
